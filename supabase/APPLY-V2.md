# 신청서 v2 운영

1. 원본 홍보 Supabase에 `lms-consultations.sql`, `apply-v2-validation.sql` 순서로 적용합니다. 기존 신청과 연결 토큰은 유지합니다.
2. 홈페이지와 LMS를 함께 배포합니다. 개인정보 동의 버전은 `2026-10-24`입니다.
3. 성별·최근 모의고사 등급·시험명/원점수·추가 메시지는 선택입니다. 중등/고1/고2/고3 선택 시 보호자 연락처가 필수입니다.
4. 만 14세 미만은 일반 폼 대신 보호자가 문의해야 합니다. 2012년생은 만 14세 이상인지 확인합니다. 이 연령 기준은 2026년 기준이며 해가 바뀌면 갱신해야 합니다.
5. 상담이 끝나면 상태를 ‘상담 종료’로 저장해야 종료일이 기록됩니다. 다시 진행하거나 등록 완료로 변경하면 종료일이 해제됩니다.
6. `consultation-retention.sql`은 영구 삭제 기능이므로 운영자 승인 후 별도 실행합니다. 새 동의문에 동의한 종료 신청만 매일 검사해 종료 후 29~30일에 삭제합니다. 기존 신청/등록 완료는 제외합니다. 숨김은 파기가 아닙니다.
7. 실제 수강 등록 시 수강 관리에 필요한 개인정보·보유기간을 별도로 안내해야 합니다. LMS와 홍보 관리자 CSV로 내보낸 파일은 DB 삭제로 지워지지 않으므로 별도 관리해야 합니다.

추가 개인정보 처리방침 검토가 필요한 범위(클라우드 처리위탁·국외 이전 등)는 이번 신청 동의문 개편만으로 대체하지 않습니다.
