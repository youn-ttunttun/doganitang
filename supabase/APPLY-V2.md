# 신청서 v2 운영

1. 원본 홍보 Supabase에 `lms-consultations.sql`, `apply-v2-validation.sql` 순서로 적용합니다. 기존 신청과 연결 토큰은 유지합니다.
2. `privacy-v3.sql`을 추가 적용한 뒤 홈페이지와 LMS를 함께 배포합니다. 새 개인정보 동의 버전은 `2026-10-24-v3`입니다.
3. 성별·최근 모의고사 등급·시험명/원점수·추가 메시지는 선택입니다. 중등/고1/고2/고3 선택 시 보호자 연락처가 필수입니다.
4. 만 14세 미만은 일반 폼 대신 보호자가 문의해야 합니다. 2012년생은 만 14세 이상인지 확인합니다. 이 연령 기준은 2026년 기준이며 해가 바뀌면 갱신해야 합니다.
5. 상담이 끝나면 상태를 ‘상담 종료’로 저장해야 종료일이 기록됩니다. 다시 진행하거나 등록 완료로 변경하면 종료일이 해제됩니다.
6. 운영자가 90일 자동 파기를 승인했습니다. `consultation-retention.sql`을 적용하면 매일 한국시간 오전 2시에 새 동의문 신청 중 종료 후 89~90일 경과한 신청을 영구 삭제합니다. 이전 30일 동의문 신청은 이전 약속대로 29~30일에 파기합니다. 동의문 없는 기존 신청과 등록 완료 상태는 제외합니다. 숨김은 파기가 아닙니다.
7. 실제 수강 등록 시 수강 관리에 필요한 개인정보·보유기간을 별도로 안내해야 합니다. LMS와 홍보 관리자 CSV로 내보낸 파일은 DB 삭제로 지워지지 않으므로 별도 관리해야 합니다.

추가 개인정보 처리방침 검토가 필요한 범위(클라우드 처리위탁·국외 이전 등)는 이번 신청 동의문 개편만으로 대체하지 않습니다.

## 누적 상담 완료 및 선택 광고 동의

- 누적 완료 수는 처음 ‘등록 완료’ 또는 ‘상담 종료’가 된 신청을 한 번만 집계합니다. 숨긴 상태에서 처리한 테스트 신청은 제외합니다. 원본 파기 후 개인 식별 키 없이 숫자 총계만 유지합니다.
- SMS·이메일 광고 동의는 기본 미선택입니다. 선택한 채널의 본인 연락처만 별도로 수집하며, 학부모 연락처나 일반 상담 연락처를 광고용으로 재사용하지 않습니다.
- 연락처는 상담 종료 후 90일 이내 또는 동의 철회 시까지입니다. 철회 요청을 받으면 LMS에서 ‘광고 수신 동의 철회’를 눌러 처리합니다.
- 이번 변경은 동의 수집·기록·철회 관리까지입니다. 실제 발송업체 연결이나 메시지 발송은 하지 않습니다. 발송 서비스 도입 시 수신거부 수단, 광고 표기, 발신자 정보, 동의 처리 통지 등도 함께 설정해야 합니다.
